# LearnLoop-AI 企业演示脚本

> 这份脚本用于面试、路演、内部评审或项目答辩。每个场景都包含背景、可导入材料、操作路径、讲解重点和可展示指标。

## 通用演示准备

建议提前准备 3 类材料：

| 材料 | 示例 | 用途 |
| --- | --- | --- |
| 岗位知识材料 | `QA 测试方法论.md`、`客服退款政策.md`、`研发入职手册.md` | 上传到知识库 |
| 典型问题 | “Verification 和 Validation 的区别是什么？” | 展示 RAG 问答 |
| 测验主题 | “边界值分析”“退款条件”“代码评审规范” | 展示自动出题和批改 |

启动方式：

```cmd
cd backend
..\venv\Scripts\python.exe -m app.main
```

```cmd
cd frontend
..\venv\Scripts\streamlit.exe run streamlit_app.py
```

## Demo 1：QA 新人训练闭环

### 背景

公司每月都有 QA 新人加入，他们需要在两周内掌握测试设计方法、缺陷流程和发布准入标准。传统培训只有文档和讲课，主管很难知道新人到底哪里没掌握。

### 演示路径

1. 进入“知识库管理”，上传一份 QA 培训资料。
2. 进入“生成笔记”，输入“软件测试基础与缺陷生命周期”。
3. 进入“知识问答”，提问“Verification 和 Validation 的区别是什么？”。
4. 进入“出题练习”，主题填写“边界值分析”，生成 5 道中等难度题。
5. 故意答错 1-2 道题，提交批改。
6. 进入“记忆中心”，展示错题、薄弱点和易混概念。
7. 进入“复习计划”，展示基于 SM-2 的复习任务。

### 讲解重点

- RAG 让企业文档从“只能搜索标题”变成“可以按语义问答”。
- Quiz Agent 将静态资料转化为可练习题库，降低培训负责人维护成本。
- Grading Agent 不只给分，还解释错误原因。
- Memory Agent 和 Scheduler Agent 让学习从一次性培训变成持续巩固。

### 推荐展示指标

- 知识库文档数、向量块数。
- 今日待复习任务数。
- 错题数、未解决错题数、掌握率。
- 高频薄弱知识点。

## Demo 2：客服政策与话术训练

### 背景

客服团队需要处理退款、投诉升级、账号安全和隐私相关问题。政策变化后，一线人员容易记错边界，造成错误承诺或质检扣分。

### 演示路径

1. 上传“退款政策”“投诉升级 SOP”“账号安全处理流程”。
2. 用“知识问答”提问：“什么情况下客服可以承诺退款？”。
3. 生成“退款条件与投诉升级”主题测验。
4. 让简答题回答故意遗漏合规边界。
5. 展示批改反馈中指出“遗漏身份校验/升级审批/禁止承诺补偿”等问题。
6. 展示记忆中心中形成的薄弱点：“退款边界”“隐私数据处理”“升级投诉标准”。

### 讲解重点

- 企业关心的不是“会不会聊天”，而是“回答是否符合最新政策和合规边界”。
- 平台能把真实工单案例转成训练题，用于新客服上岗前演练。
- 主管可以根据薄弱点安排定向复训。

### 推荐展示指标

- 质检扣分项下降。
- 新客服独立接线周期缩短。
- 高频政策误答数量。

## Demo 3：合规制度培训

### 背景

金融、医疗、制造等行业需要定期进行合规培训。传统 LMS 只能证明员工“看过课程”，不能证明员工能在案例中识别风险。

### 演示路径

1. 上传合规条款或制度节选。
2. 生成“数据隐私与权限审批”结构化笔记。
3. 生成案例判断题和简答题。
4. 提交一个只答对结论但遗漏风险点的答案。
5. 展示 Grading Agent 如何按 Rubric 给出部分分并指出遗漏项。
6. 展示学习记录可被用于审计追踪。

### 讲解重点

- 合规培训需要可追溯的学习、测评和复习记录。
- 对高风险题目，企业版可增加专家审核流。
- 敏感资料可以通过本地模型或私有模型网关处理。

### 推荐展示指标

- 合规测评通过率。
- 高风险条款错题率。
- 复训完成及时率。

## Demo 4：研发新人入职

### 背景

研发团队的知识分散在架构文档、接口规范、部署手册、故障复盘和代码评审评论中。新人常常重复问同样的问题。

### 演示路径

1. 上传“项目架构说明”“部署流程”“代码评审规范”。
2. 提问：“服务启动失败时应先检查哪些配置？”。
3. 生成“后端服务启动与配置管理”笔记。
4. 生成 5 道代码规范/部署排障题。
5. 展示错题和复习计划。

### 讲解重点

- 项目文档被转化为新人可查询、可练习、可复习的知识资产。
- 导师答疑从重复问题转向高价值辅导。
- 系统能把事故复盘变成训练题，减少同类事故复发。

### 推荐展示指标

- 新人首次独立交付周期。
- 导师答疑时长。
- 代码评审基础问题数量。

## 面向企业评审的一句话总结

LearnLoop-AI 的企业价值不是简单生成内容，而是把企业知识资料转成“可检索、可练习、可批改、可追踪、可复习”的持续学习闭环，最终服务于岗位胜任力提升和组织知识沉淀。
